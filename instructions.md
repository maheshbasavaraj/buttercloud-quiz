This project is an interactive platform that gives realistic project requirements (scenarios) and challenges users to select the best tech-stack and architecture choices across frontend, backend, DB, infra, and patterns — then scores and teaches them why choices are right/wrong.




# Instructions for scenario generation.

- Keep scenarios real.
- Ensure congruence between scenario requirements and the questions being asked.
- Questions should test the student's understanding of the tech stack.
- Students should make real choices based on real requirements and tech stack choices for each category of the requirements.
- Don't keep a cookie-cutter set of requirement types like UI/UX. Requirement types should be set based on the app's priorities in the real world (e.g., UI for mobile apps , security for banking apps etc).
- Use concise scenario and requirement descriptions.
- The JSON should follow a consistent format for all scenarios and should have same well-structured format for all scenarios.
- the options should come with rating( best, good , acceptable, poor)  , score and justification for the score why it is rated good or poor etc. 
- refer attached sample scenario for the format and context on how to generate an awesome scenarios.
